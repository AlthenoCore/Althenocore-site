Univers Cloud

L'Univers Cloud comprend nos solutions de serveurs virtuels propulsés par KVM. Nous proposons des VM à usage général, de stockage ou axées performance.

Standard Cloud

Standard Cloud est conçue pour les personnes qui ont besoin d'un serveur Linux pour une utilisation standard avec de bonnes performances et un bon prix.

Education Cloud

Education Cloud est conçue pour les étudiants qui ont besoin d'un serveur Linux pour leurs projets d'études avec le meilleur prix possible.

Performance Cloud

Performance Cloud est conçue pour les personnes qui ont besoin d'un serveur Linux ou Windows à haute performance pour une utilisation intensive.

Storage Cloud

Storage Cloud est conçue pour les personnes qui ont besoin d'un serveur Linux avec un grand espace disque pour leurs sauvegardes ou stockage de données.

Pourquoi choisir l'offre Cloud ?

L'offre VPS Cloud vous permet de bénéficier de serveurs virtuels disponibles immédiatement, ultra-flexibles et évolutifs en un clic depuis votre espace client.

1

Nombreux OS

L'offre Cloud comprend de nombreux OS en réinstallation automatique, si le système d'exploitation de votre choix n'est pas disponible, nous pouvons l'ajouter sur simple demande.

2

Snapshots sécurisés

Les snapshots vous permettent, en cas d'erreur de manipulation ou mise à jour problématique, de revenir en arrière en quelques secondes seulement.

3

Protection DDoS

Parce que les DDoS ne doivent pas rendre vos applications indisponibles, nos offres Cloud sont assorties d'une protection multi-niveaux contre les attaques DDoS.

4

nVME et SSD locaux

Notre offre Standard Cloud fonctionne sur des caches nVME et notre offre Performance Cloud sur des disques SSD locaux afin d'obtenir les meilleures performances.
